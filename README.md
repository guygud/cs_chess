# Dust2, тестовая сборка

Мини-игра на распределение сил. Игрок атакует, бот защищается. Одна карта, матч до 3 побед и\u00A0не больше 5 раундов.

Все числа баланса лежат в\u00A0`src/config.js`. Движок их не дублирует.

## Как открыть

Модули не работают с\u00A0`file://`. Локально:

```bash
python3 -m http.server 8080
```

Дальше [http://localhost:8080](http://localhost:8080).

Проверка формул и зеркальных партий бот против бота:

```bash
node src/sim.js
node src/sim.js 5000
node src/sim.js 0
```

Последняя команда только гоняет проверки, без партий. Зерно генератора задаётся третьим аргументом.

## Раунд

1. Покупка. Деньги списываются в\u00A0конце раунда, купленное сгорает.
2. Расстановка по точкам A, Мид и\u00A0B. Сайт переброса с\u00A0мида выбирается сейчас, до вскрытия.
3. Вскрытие. Сначала мид, потом переброс, потом сайты.

Раунд берёт атака, если её сила хотя бы на одном сайте строго выше защиты. Флеш меняет ничью в пользу атаки. Сайт без бойцов атаки занять нельзя, даже флешем.

При 5 раундах и\u00A0победителе в\u00A0каждом ничья матча не случается: счёт 2:2 после четырёх раундов ломает пятый. Экран ничьей остаётся на случай, если в\u00A0конфиге поменять `maxRounds`.

## Сила

Сырая сила точки\u00A0— сумма силы оружия бойцов на ней.

AWP берёт `longStrength` на длинной линии (A и\u00A0Мид) и\u00A0`shortStrength` на короткой (B). Остальное оружие от линии не зависит.

Защита на сайте умножается на `defenderSiteMultiplier`. На миде множитель равен 1.

Ротатор в\u00A0расстановке не стоит. После переброса с\u00A0мида он приходит на сайт, где у\u00A0атаки больше силы. При равенстве силы смотрит, где больше бойцов. При новом равенстве идёт на `rotatorTieSite`. Вклад: сила оружия × `rotatorMultiplier` × множитель сайта. Если атаки на сайтах нет, ротатор не выходит.

Смоук вычитает `defensePenalty` из уже посчитанной силы защиты, но не ниже нуля. Несколько смоуков на одной точке складываются. Смоук бьёт и\u00A0по ротатору, если тот уже пришёл на точку.

Флеш силу не меняет.

Мид считается до переброса. Ничья на миде по умолчанию достаётся `tieWinner`. Сторона без бойцов на миде выиграть его не может. Если бойцов нет у\u00A0обеих, переброса нет.

Победитель мида переносит `midTransferFighters` самых сильных своих бойцов с\u00A0мида на сайт. Атака несёт их на сайт, выбранный заранее. Защита несёт на сайт, где у\u00A0атаки больше силы: это награда за мид. Сила перенесённого бойца считается заново на новой точке, поэтому AWP с\u00A0мида на B слабеет.

Дальше выходит ротатор, потом применяется смоук, потом сравниваются сайты.

Килл-фид декоративный. На точке победитель получает `ceil(разница сил / killfeedDivisor)` фрагов и\u00A0не больше, чем бойцов у\u00A0противника на этой точке. На исход раунда это не влияет. Фраги мида считаются до переброса, фраги сайтов\u00A0— после.

## Экономика

Старт: `startMoney` у\u00A0обеих сторон.

Победа платит `winReward` и\u00A0обнуляет серию поражений.

Поражение платит `lossBase + lossStreakStep × min(серия до этого раунда, maxLossStreakSteps)`. Первое поражение\u00A0— это база. Второе подряд добавляет один шаг, дальше до потолка.

Кошелёк после раунда: было − потрачено + награда.

На стартовых 800\u00A0$ винтовка за 2\u202F700\u00A0$ ещё не берётся. Полный набор из пяти винтовок стоит 13\u202F500\u00A0$. Бот покупает винтовки только на всех пятерых сразу, иначе остаётся на пистолетах и\u00A0не берёт AWP. За матч до трёх побед такая сумма обычно не набирается, поэтому стоимость набора бота часто 0\u00A0$. Частичную закупку может сделать только игрок.

## Бот

Расстановка четырёх бойцов\u00A0— взвешенный случайный шаблон из `defenseTemplates`. Пятый всегда ротатор. Историю игрока бот не читает: так виден базовый винрейт, а\u00A0не подстройка.

`node src/sim.js` гоняет ту же закупку за атаку и\u00A0шаблоны из `sim.attackTemplates`. Это не сила живого игрока, а\u00A0зеркало без утилиты.
